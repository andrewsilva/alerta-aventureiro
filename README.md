# Alerta Aventureiro

Plataforma colaborativa para registrar e acompanhar problemas de zeladoria urbana do bairro **Aventureiro, em Joinville/SC**: buracos, lixo e entulho, calçadas quebradas e alagamentos.

Projeto da disciplina Projeto de Software (CST em Análise e Desenvolvimento de Sistemas), ligado ao **ODS 11, Cidades e Comunidades Sustentáveis**.

> Em desenvolvimento. As instruções de instalação serão adicionadas junto com o código.

## Estrutura prevista

- `api/`: API REST em Node.js (Express) com PostgreSQL
- `web/`: aplicação web responsiva (PWA) em Angular
- `docs/adr/`: registros de decisão de arquitetura
